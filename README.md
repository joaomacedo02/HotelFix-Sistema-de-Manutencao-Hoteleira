# 🏨 HotelFix – Sistema de Manutenção Hoteleira

Projeto desenvolvido na disciplina **Desenvolvimento de Aplicação Web Front-End**, no 1º semestre de Análise e Desenvolvimento de Sistemas (PUC Minas). Foi eleito o **melhor projeto do curso no 1º semestre**. 🏆

O HotelFix permite uma comunicação rápida entre **hóspedes, gerentes de setor, funcionários e gerente geral**:
- Hóspedes relatam problemas e solicitam serviços de forma simples.
- Funcionários e gerentes acompanham e gerenciam as solicitações de forma organizada.

## ✨ Funcionalidades

- Login de funcionários
- Relato de problemas e solicitações de manutenção pelo hóspede
- Painel inicial com a quantidade de chamados **abertos, em andamento e solucionados**
- Detalhamento e atualização das demandas
- Relatórios
- Interface responsiva
